# Static Image Assets Directory for MAKO User Guide

Place your manually captured screenshots in this directory with the following filenames:

1. `01_sidebar_settings.png` - Screenshot of the sidebar (World and Simulation parameters).
2. `02_create_platform.png` - Screenshot of the Create Platforms page (Platform details, movement, and sensors).
3. `03_sensor_fov_diagram.png` - Diagram or illustration explaining the Cartesian counter-clockwise FOV vs Navigational heading.
4. `04_create_sonobuoys.png` - Screenshot of the Create Sonobuoys page (Sonobuoy coordinates and fusion settings).
5. `05_home_ready_status.png` - Screenshot of the Home page with the green "Simulation Ready" status card and YAML generation button.
6. `06_results_analytics_kpi.png` - Screenshot of the Results page - Detection Analytics tab (KPI cards, fleet detection probability, and charts).
7. `07_results_animation.png` - Screenshot of the Results page - Animation playback tab (2D track visualization).
